# Cyber Threat Identification — Day 3 Task

## Objective
Recognize and classify common cybersecurity threats: phishing, malware,
ransomware, social engineering, and credential theft.

## Approach
Researched each threat type and documented it in a structured table
covering: the threat, its typical target, its impact, and prevention
measures. Sources used include OWASP, CISA, and standard cybersecurity
references.

## Deliverable
`threat-classification-table.md` — a table classifying 5 common cyber
threats by target, impact, and prevention strategy.

## Outcome
Gained a clearer understanding of how different threat types operate,
who they target, and the layered defenses (technical + human) needed
to prevent them. This forms a foundation for identifying threats in
real-world security assessments.
